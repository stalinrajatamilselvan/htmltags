1.Head Tag

The head tag is a container for metadata (data about data). It sits between the html tag and the body tag, holding information like document titles, character sets, styles, and scripts that are not displayed directly on the webpage.

Example

<head>
  <meta charset="UTF-8">
  <title>Page Title Here</title>
</head>

2.Title Tag

The title tag defines the title of the document. This text appears in the browser's title bar or tab, as well as in search engine results.

Example

<title>Html Tags and Info</title>

3.Heading Tag

The h1 through h6 heading tags in HTML define section titles, establishing a content hierarchy for users and search engines.

Example

Heading 1 - Main Title

Heading 2 - Major Section

Heading 3 - Subsection

Heading 4 - Minor Heading

Heading 5 - Small Subheading
Heading 6 - Smallest Heading

4.Paragraph Tag

The p tag in HTML defines a paragraph. Browsers automatically add a small amount of vertical space (margin) before and after each p element to separate text blocks.

Example

This is the first paragraph of text on the page.

This is a second paragraph, which automatically starts on a new line with space above it.

5.Line Break Tag

The br tag inserts a single line break in text. It is a self-closing tag and is useful for content where division of lines is significant, such as in an address or a poem.

Example

This is line 1 of text.
This is line 2 on a new line.
This is line 3 after another break.

6.List Tags

List tags in HTML group related items. You can create bulleted lists with ul (unordered) or numbered lists with ol (ordered).

Example

Unordered List:

  • Apples
  • Bananas

Ordered List:

  1. First Step
  2. Second Step

7.Table Tag

The table tag in HTML creates a structured layout of rows and columns to display data.

  • table: Wraps the entire tabular structure.
  • tr (Table Row): Defines a single horizontal row.
  • th (Table Header): Defines a header cell (centered and bold by default).
  • td (Table Data): Defines a standard data cell.
  • thead, tbody, tfoot: Optional tags to group header, body, and footer sections.

Example

Name Age
Alice 25
